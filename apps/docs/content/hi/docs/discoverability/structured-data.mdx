Blume प्रत्येक पृष्ठ के `<head>` में [schema.org](https://schema.org) JSON-LD उत्सर्जित करता है ताकि खोज इंजन आपकी सामग्री को समझ सकें। यह डिफ़ॉल्ट रूप से चालू रहता है:

```ts blume.config.ts lineNumbers
seo: {
  structuredData: true,
}
```

प्रत्येक पृष्ठ में शामिल होते हैं:

- साइट की पहचान के लिए एक **WebSite** नोड,
- पृष्ठ स्वयं एक **article** के रूप में — ब्लॉग पोस्ट के लिए `BlogPosting`, चेंजलॉग और दस्तावेज़ों के लिए `TechArticle` — अपने विवरण और प्रकाशन तिथि के साथ,
- नेविगेशन ट्रेल से निर्मित एक **BreadcrumbList**।

जब [`deployment.site`](/docs/deployment) सेट होता है, तो URL निरपेक्ष होते हैं। [`seo.noindex`](/docs/discoverability/metadata#per-page-overrides) से चिह्नित पृष्ठ छोड़ दिए जाते हैं। जब [`lastModified`](/docs/configuration#last-modified) चालू होता है, तो प्रत्येक पृष्ठ की तिथि `dateModified` के रूप में भी उत्सर्जित होती है।

## साइट की पहचान [#site-identity]

WebSite नोड यह बताता है कि एक साइट मौजूद है; यह नहीं बताता कि वह _क्या_ है या उसे _कौन_ चलाता है — और AI एजेंट आपकी अनुशंसा या उद्धरण देने से पहले JSON-LD को इसी के लिए पढ़ते हैं। दो वैकल्पिक ब्लॉक इस कमी को पूरा करते हैं, और दोनों को `deployment.site` की आवश्यकता होती है (क्योंकि इन नोड्स में निरपेक्ष पहचानकर्ता होते हैं):

```ts blume.config.ts lineNumbers
seo: {
  organization: {
    name: "Acme", // defaults to the site title
    email: "hello@acme.com",
    telephone: "+1 555 0100",
    address: { addressLocality: "Sydney", addressCountry: "AU" },
    logo: "/logo.svg",
    sameAs: ["https://github.com/acme", "https://x.com/acme"],
  },
  software: {
    license: "MIT",
    operatingSystem: "Node.js 22+",
    price: 0, // emitted as an Offer; 0 marks it free
    sameAs: ["https://www.npmjs.com/package/acme"],
  },
}
```

`organization` प्रत्येक पृष्ठ में एक **Organization** नोड जोड़ता है — WebSite और article नोड्स इसे `publisher` के रूप में उद्धृत करते हैं — जिसमें ईमेल और टेलीफ़ोन एक `ContactPoint` के रूप में (`contactType` का डिफ़ॉल्ट `"customer support"` है) और पता एक `PostalAddress` के रूप में होता है; यही वे दो फ़ील्ड हैं जिन्हें व्यवसाय-सत्यापन जाँचें खोजती हैं। `name` और `url` का डिफ़ॉल्ट साइट के मान होते हैं; रूट-सापेक्ष `logo` को किसी भी पृष्ठ URL की तरह निरपेक्ष बना दिया जाता है।

`software` मुखपृष्ठ में एक **SoftwareApplication** नोड जोड़ता है: उत्पाद का नाम और विवरण (डिफ़ॉल्ट रूप से साइट के), `applicationCategory` (डिफ़ॉल्ट `"DeveloperApplication"`), ऑपरेटिंग सिस्टम, लाइसेंस, `price` सेट होने पर एक `Offer`, और `sameAs` में रजिस्ट्री या रिपॉज़िटरी URL। सभी डिफ़ॉल्ट अपनाने के लिए `software: true` पास करें। संगठन, यदि कॉन्फ़िगर किया गया हो, तो उसे इसके `publisher` के रूप में उद्धृत किया जाता है।

## कस्टम पृष्ठ [#custom-pages]

`PageLayout` के माध्यम से रेंडर किया गया कोई कस्टम [`.astro` पृष्ठ](/docs/advanced/custom-pages) वही `WebSite` ग्राफ़ उत्सर्जित करता है, ताकि कोई मार्केटिंग मुखपृष्ठ ऐसा एकमात्र URL न रह जाए जिसमें संरचित डेटा न हो। इस सेटिंग के साथ समन्वयित रखने के लिए `structuredDataEnabled={config.structuredData}` पास करें, या केवल उसी पृष्ठ के लिए इसे बंद करने के लिए `structuredDataEnabled={false}` पास करें।
